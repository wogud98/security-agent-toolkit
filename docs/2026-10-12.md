## 찾아보고 알게 된 것
보안 담당자가 패킷을 직접 열어 보는 이유는 경보나 로그는 "무슨 일이 있었다"만 알려 주지만, 패킷에는 실제로 오간 내용(누가 누구에게 어떤 요청을 보냈고 무엇이 돌아왔는지)이 그대로 남아 있어서, 공격이 진짜였는지와 무엇이 새어 나갔는지를 확인할 수 있기 때문

*패킷*은 네트워크로 데이터를 보낼 때 잘게 나눈 한 조각으로, 보내는 곳·받는 곳 주소 같은 머리말(헤더)과 실제 내용(데이터)으로 이루어져 있음

*Npcap* 은 Wireshark 가 네트워크 카드를 지나는 패킷을 Windows 에서 붙잡을 수 있게 해 주는 캡처용 부품이라, 이것이 없으면 Wireshark 가 인터페이스 목록을 못 보여 줌
| (파이프) 는 앞 명령의 결과를 화면에 내지 않고 뒤 명령에게 넘기는 기호로, `tasklist | grep Code` 처럼 grep 과 쓰면 결과 중 원하는 줄만 남길 수 있음

## 막힌 것
    - (생소한 것)
*| (파이프 · pipe)*
    앞 명령의 결과를 화면에 내지 않고 뒤 명령에게 넘깁니다

*grep 글자 (그렙)*
    넘겨받은 결과에서 그 글자가 든 줄만 남깁니다
