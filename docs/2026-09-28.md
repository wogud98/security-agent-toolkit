## 찾아보고 알게 된 것

서버는 대부분 리눅스 환경에서 운영되기 때문에 보안 담당자가 명령어를 사용해 서버의 파일과 시스템을 관리하고 확인할 수 있어야 한다.

개발자와 보안 담당자는 GitHub를 이용해 코드를 저장하고 버전을 관리하며, 변경 이력을 확인하고 다른 사람과 코드를 공유할 수 있다.

터미널은

마우스로 화면을 조작하는 대신 명령어를 입력하여 컴퓨터의 파일이나 프로그램을 다루는 프로그램이다.

경로(path)는

파일이나 폴더가 컴퓨터의 어느 위치에 있는지를 나타내는 주소이다.

Git Bash는

Windows에서 Linux/Unix 계열의 명령어와 Git 명령어를 사용할 수 있도록 해주는 터미널이다.
