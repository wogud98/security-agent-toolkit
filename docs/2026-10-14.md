## 찾아본 것
서버에서 로그를 옮기고 백업하는 방법:
```bash
cp: 로그 파일을 복사해 백업본 생성

mv: 로그 파일을 다른 폴더로 이동하거나 파일명 변경

mkdir: 백업용 폴더 생성

rm: 불필요한 로그 파일 삭제

백업 전 pwd, ls로 현재 경로와 대상 파일 확인
```

## 오늘 새로 쓴 명령
touch, cp, mv, rm, Tab 자동 완성

## 찾은 옵션
폴더째 복사 : cp -r folder folder2  / 
덮어쓰기 전에 묻기 : cp -i file folder  / 
폴더째 지우기 : rm -r folder

## mv 의 두 가지 쓰임
이름 바꾸기: mv old.log new.log
옮기기: mv app.log backup/

## 막힌 것
**-r** **-i** 같은 옵션

## 알아야 할 팁

### 1. 파일·폴더 기본 작업

- `cp`: 파일 복사, 원본은 유지.
- `mv`: 파일 이동 또는 이름 변경.
- `mkdir`: 폴더 생성.
- `rm`: 파일 삭제. 휴지통을 거치지 않으므로 실행 전에 `ls`로 대상 확인.
- `cat`: 파일 내용 출력.

### 2. 파일·폴더 확인

- `pwd`: 현재 작업 디렉터리 확인. 작업 전 경로를 확인하는 습관 들이기.
- `ls`: 현재 폴더의 파일·폴더 목록 확인.
- `ls backup`: `backup` 폴더 내부 확인.
- `ls -a`: 숨김 파일까지 표시. 파일명 앞에 `.`이 붙으면 일반적으로 숨김 파일.
- `ls -l`: 권한, 소유자, 크기 등 상세 정보 표시.
- `ls -al`: 숨김 파일과 상세 정보를 함께 표시.
- `cat -n a.log`: 파일 내용을 줄 번호와 함께 출력.

### 3. 복사·이동·삭제 옵션

- `-r`: 폴더 내부까지 재귀적으로 처리. `cp -r`은 폴더 복사, `rm -r`은 폴더 삭제.
- `-i`: 덮어쓰기 또는 삭제 전에 확인 요청. `n`을 입력하면 취소.
- `-a`: 명령어마다 의미가 다름. `cp -a`는 파일 속성 등을 보존하며 복사, `ls -a`는 숨김 파일 표시.
- `-f`: 강제 실행 또는 확인 생략. `rm -f`는 삭제 확인 없이 파일을 지우므로 주의.
- `-v`: 지원하는 명령어에서 처리 과정을 출력. 예: `cp -v a.log b.log`.

### 4. 폴더 생성 및 복사 응용

- `mkdir -p work/logs/2026`: 필요한 상위 폴더까지 한 번에 생성.
- `cp -r backup backup2`: 폴더와 내부 파일을 `backup2`로 복사.
- `cp -a backup backup2`: 폴더를 복사하면서 권한·시간 등 파일 속성을 보존.
- `-p`: `mkdir -p`에서 상위 폴더도 함께 생성하도록 지정.

### 5. 경로와 옵션 사용법

- 상대 경로: `backup/a.log`처럼 현재 작업 디렉터리를 기준으로 지정.
- 절대 경로: `/home/user/backup/a.log`처럼 루트(`/`)부터 경로 지정.
- 옵션 조합: `ls -al`처럼 옵션을 조합할 수 있지만, 의미와 지원 여부는 명령어마다 다름.
- 덮어쓰기 주의: `cp`와 `mv`는 기존 파일을 덮어쓸 수 있으므로 중요한 파일에는 `-i` 사용.
- 삭제 주의: `rm -r`은 폴더와 내부 파일을 삭제하며, `rm -rf`는 확인 없이 강제 삭제하므로 실습에서는 가급적 사용하지 않기.
