## 오늘 새로 쓴 명령
git config, git add, git commit, git push

## 찾아보고 알게 된 것
add 와 commit 과 push 는

add는 커밋할 파일을 골라 staging area에 올리는 것이고,
commit은 stage에 올린 변경 내용을 내 PC의 Git 기록으로 남기는 것이다.
push는 내 PC에 있는 commit을 원격 저장소인 GitHub로 보내는 것이다.

untracked · tracked · staged 는

untracked는 Git이 아직 추적하지 않는 새 파일이고,
tracked는 Git이 이미 추적하고 있는 파일이다.
staged는 다음 commit에 포함시키기로 git add를 통해 선택한 상태이다.
