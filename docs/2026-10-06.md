## 찾아보고 알게 된 것

API 키는

API를 사용하는 사용자를 식별하고 접근 권한을 확인하기 위한 인증 수단이며, API 사용량을 추적하거나 제한하는 데 사용된다.

무료 등급은

비용을 지불하지 않고 사용할 수 있지만, API 호출 횟수나 사용량 등의 제한이 있다.

보안 담당자가 다루는 서버는

Linux 운영체제를 많이 사용하며, Git Bash를 사용하면 Windows에서도 Linux/Unix 계열의 명령어와 Git 명령어를 사용할 수 있다.

깃배시를 쓰면

Windows에서도 bash 기반 명령어를 사용할 수 있어 Linux 서버 환경과 비슷한 방식으로 명령어를 연습할 수 있다.

## 키가 틀렸을 때와 키가 없을 때의 차이

키가 틀리면 인증할 수 없는 키이기 때문에 `UNAUTHENTICATED` 오류가 발생하고, 키가 없으면 API에 접근할 권한이 없어 `PERMISSION_DENIED` 오류가 발생한다.
