- (가) 실행한 출력 전체를 붙여 넣고, 읽기 성공한 줄과 읽기 실패한 줄이 각각 몇 줄인지, 읽기 실패한 줄이 어떤 줄인지 적어 주세요.

  - 답:
출력은 다음과 같고, 읽기 성공은 28줄, 읽기 실패는 2줄입니다.
읽기 실패한 두 줄은 GET /board/5 HTTP/1.1 에서 잘린 줄과 - 하나만 있는 줄입니다. 큰따옴표가 두 개보다 적어서 읽지 못했습니다.

## 6교시 · 이상 징후 가르기와 SIEM(심)

### 문제 6-1 · 읽은 로그 줄을 정상 · 오류 · 의심으로 가르기

- (가) 실행한 출력 전체를 붙여 넣고, 분류별 요청 수와, 의심으로 분류한 요청 중 같은 주소에서 반복된 것을 적어 주세요.
  - 쓸 내용: ① 출력 전체(코드 상자에 붙여 넣기) ② 분류별 요청 수 ③ 같은 주소에서 반복된 의심 요청
  - 답:정상 15, 오류 5, 의심 8 입니다.
의심 8개 중 같은 주소에서 반복된 것은 203.0.113.50 의 POST /login 401 이 5번과, 같은 주소의 /admin · /admin/users 403 이 2번입니다. 198.51.100.77 의 /admin 403 은 한 번뿐


  - 쓸 내용: ① 놓친 예 두 가지 ② 각각 왜 놓쳤는지
  - 답:
```bash

198.51.100.90 의 /.env · /wp-login.php · /phpmyadmin 은 「오류」(404)입니다. 한 줄씩은 흔한 404 이지만 1초 간격으로 연속해서 서버에 무엇이 있는지 확인하는 탐색인데, 규칙이 같은 주소의 반복을 보지 못했습니다.

그 밖에 파일 크기, 시각, 요청 도구(python-requests, curl)도 보지 않아 사람이 보면 의심스러운 단서를 쓰지 못합니다. 이런 것을 놓치는 것이 미탐입니다.
```

  - 답:
```bash
한 예: ② 클라우드(SaaS) 또는 ④ 관리형 보안관제 서비스를 고릅니다.
```
