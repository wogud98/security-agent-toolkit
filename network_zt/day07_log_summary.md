# 정산 포털 정책 로그 점검 결과
## 결론
- 거부하기로 정한 요청 중 실제로는 통과된 건이 있었고, 판단하는 곳을 거치지 않은 접속도 확인되었습니다. 정상 업무 요청이 자주 추가 확인을 받는 문제도 있었습니다.
## 근거
- 요청 101(02:14, seoyeon): 판단은 거부였지만 앱은 응답 번호 200 으로 처리했습니다. 12건 중 3건이 판단과 다르게 처리되었습니다. (3-1)
- 요청 201(12:34, seoyeon): 판단 기록이 없는데 앱에는 200 으로 남아 있습니다. (3-1)
- 정상 업무 요청 6건이 모두 추가 확인을 받았습니다. 현재 규칙은 정상 요청을 의심한 경우가 6건, 위험 요청을 놓친 경우가 0건이고, 대량 조회 기준을 50건으로 올린 안 A 는 각각 0건과 1건입니다. (4-1)
## 권고
- 판단 결과가 앱에서 그대로 적용되는지 앱보다 먼저 요청을 받는 곳의 설정과 처리 순서를 점검합니다. 요청 101 이 왜 통과했는지는 기록만으로 알 수 없으므로 앱 처리 기록을 확인합니다.
- 대량 조회 기준을 50건으로 올리는 안 A 를 적용하되, 49건 이하의 해외 대량 조회를 놓치지 않도록 해외 접속 같은 다른 신호를 함께 봅니다.
