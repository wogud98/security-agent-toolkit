### 문제 2-1 · 내 IP 를 2진수로

- (가) 두 번째 파일(`warmup_2_1b.py`, 내 IPv4 주소)의 출력 네 줄:

- (나-1) `format(number, "08b")` 가 마디 하나의 10진수를 어떤 형태의 글자로 바꾸는지, 내 출력 한 줄을 예로 들어 설명하세요.
  - 답: 10진수를 8bit의 2진수로 바꿈

- (나-2) `"08b"` 에서 `08` 을 빼고 `"b"` 만 쓰면 `10` 은 어떻게 출력되나요?
  - 답:  - 자리수를 지정하지 않으므로 앞에 0을 채우지 않고 출력합니다.

- (나-3) 마디마다 8자리로 맞춰 써야 하는 이유를 설명하세요.
  - 답: IP 주소를 2진수로 변환할 때는 각 옥텟(예: 192.168.0.1)을 8비트로 표현해야 하므로 08b를 사용하며, b만 사용하면 앞자리 0이 생략되어 옥텟별 비트 길이가 달라지기 때문에 32비트 IP 주소를 정확한 형태로 다루기 어려움

- (다-1) IPv4 주소가 32비트라는 것과 마디 하나가 `0` ~ `255` 사이의 값만 가진다는 것은 어떻게 이어지나요? 마디 수와 비트 수를 근거로 설명하세요.
  - 답: 4개 마디, 각 마디당 8비트 4*8 = 32비트. 각 마디당 가지는 8비트값이 표현할 수 있는 값이 0~255

- (다-2) 32비트로 만들 수 있는 주소의 개수: 256^4

- (다-3) 그 개수가 나오는 계산 과정을, 비트 한 자리에 들어갈 수 있는 값의 가짓수와 자리 수를 넣어 단계별로 설명하세요.
  - 답: IPv4는 8bit씩 4개 마디를 가져 총 32bit이다. 1개 비트가 표현할 수 있는 수는 0과 1의 이진수로,
  마디당 8비트가 표현할 수 있는 수는 0부터 255 즉 256가지이다. 총 4개마디임으로 256^4의 수가 표현 가능한 것이다.

- (다-4) 이 수의 한계가 사설 IP 와 NAT 를 쓰게 된 것과 어떻게 이어지는지 설명하세요.
  - 답: IPv4 주소가 약 43억 개로 한정되어 모든 기기에 공인 IP를 하나씩 할당하기 어려워지자, 내부 네트워크에서는 사설 IP를 사용하고 NAT를 통해 여러 기기가 하나의 공인 IP를 공유하도록 하여 IPv4 주소 부족 문제를 완화함

  - 답: 정적 NAT이 적합. 내부 서버의 사설 IP와 공인 IP를 고정 연결해 외부 사용자가 일관된 주소로 접속할 수 있기 때문입니다.

  - 답: 두 주소가 일치하지 않는다면 여러 라우터를 거치는 경로, 라우팅 설정 변경, VPN 사용 등의 상황을 의심할 수 있다. tracert의 첫 번째 홉은 실제 패킷이 처음 도달한 장비이고, 기본 게이트웨이는 PC에 설정된 기본 경로의 다음 장비이므로 환경에 따라 다를 수 있다.

- (다-1) 기본 경로(`0.0.0.0/0`)는 어떤 목적지로 갈 때 쓰이나요?
  - 답:  본 경로는 라우팅 표에서 목적지에 맞는 다른 경로를 찾을 수 없을 때 패킷을 전달하는 데 사용되며, 일반적으로 인터넷처럼 다양한 외부 네트워크로 통신할 때 활용된다.

- (다-2) 기본 경로의 `/0` 은 무엇을 뜻하나요?
  - 답: /0은 네트워크 주소를 구분하는 네트워크 비트가 0개라는 뜻으로, 모든 IPv4 목적지 주소와 일치하는 경로를 의미한다.

- (다-3) 라우팅 표에서 기본 경로가 빠지면 맞는 줄이 없는 목적지로 가는 패킷은 어떻게 되나요?
  - 답: 기본 경로가 없고 목적지에 맞는 다른 경로도 없다면 라우터나 PC는 해당 패킷을 전달할 경로를 찾지 못해 패킷을 폐기한다. 

- (다-4) 이때 같은 망 통신과 인터넷 통신이 각각 어떻게 되는지 이유와 함께 설명하세요.
