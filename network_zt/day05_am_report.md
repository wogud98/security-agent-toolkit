## 2교시 · 클라우드 · SaaS

### 문제 2-1 · 서비스 형태 네 개 가르고 먼저 볼 기록 정하기

- (가-1) 서비스 A · B · C · D 는 각각 IaaS · PaaS · SaaS 중 무엇인가요?
  - 쓸 내용: 「A: … / B: … / C: … / D: …」 네 개
  - 답:
  서비스 A = IaaS, 서비스 B = PaaS, 서비스 C = SaaS, 서비스 D = PaaS 입니다. D 는 계정을 회사가 관리해도 운영체제와 실행 환경은 업체가 관리하고, 회사는 프로그램과 데이터를 올리므로 PaaS 입니다.

- (가-2) 서비스 C 에서 회사가 직접 맡는 것 세 가지를 적어 주세요.
  - 쓸 내용: 안내 2.1 의 SaaS 줄에 나온 「내가 맡는 것」 세 가지
  - 답: 서비스 C 에서 회사가 맡는 것은 직원 계정 · 접근 권한 · 서비스에 넣은 데이터입니다.

- (나) 🔍 서비스 C 에는 방화벽 규칙을 직접 걸 수 없습니다. 그러면 회사에 남는 통제 수단은 무엇일까요?
  - 쓸 내용: ① 남는 통제 수단 한 가지 ② 그것으로 정할 수 있는 것 한 가지
  - 답: 방화벽 규칙은 걸 자리가 없으므로 계정과 권한이 남습니다. 이것으로 누가 로그인할 수 있는지, 로그인한 사람이 무엇을 할 수 있는지를 정합니다.

- (다) 서비스 A 와 서비스 C 에서 사고가 났을 때, 회사가 먼저 볼 기록은 각각 무엇인가요?
  - 쓸 내용: 「서비스 A: … / 서비스 C: …」
  - 답: 서비스 A 는 회사가 관리하는 서버이므로 서버의 운영체제 로그와 방화벽 로그를 먼저 봅니다. 서비스 C 는 그 서비스의 로그인 기록을 먼저 봅니다.

### 문제 2-2 · 방화벽 로그에 없는 접속 찾고 조치 보고 평가하기

- (가) 방화벽 로그에 짝이 없는 로그인은 몇 건이고, 번호는 무엇인가요?
  - 쓸 내용: 「… 건 / 번호: …」 번호는 `1, 4, 6` 처럼 숫자로 써도 됩니다
  - 답: 짝이 없는 로그인은 3건이고 번호는 ①④⑥ 입니다. (②③⑤ 는 방화벽 로그에 짝이 있습니다.) ①번은 회사 방화벽을 지나지 않아 방화벽 로그에 남지 않으므로, 방화벽 로그만으로는 알 수 없고 SaaS 의 로그인 기록에서만 볼 수 있습니다.

- (나) 🔍 방화벽 로그에 없는 접속 중 가장 수상한 것은 몇 번이고, 그렇게 본 근거는 무엇인가요?
  - 쓸 내용: ① 번호 하나 ② 근거 두 가지 이상(시각 · 접속한 IP · 같은 계정의 다른 접속 중에서 골라서)
  - 답: 가장 수상한 것은 ①번입니다. 근거 첫째, 시각이 새벽 03:12 입니다. 둘째, 같은 계정 lee 의 다른 접속(③ 09:15)은 사내 IP 203.0.113.10 인데 ①번은 낯선 IP 192.0.2.88 입니다. ④ · ⑥번은 다른 계정이고 시각이 근무 시간이라 정상적인 재택 접속일 수 있습니다.

- (다) 담당자 보고에서 **확인된 것**과 **확인하지 못한 것**을 각각 적어 주세요.
  - 쓸 내용: 「확인된 것: … / 확인하지 못한 것: … (두 가지 이상)」
  - 답: 확인된 것: lee 계정의 비밀번호가 바뀌었습니다. 앞으로 같은 비밀번호로는 로그인할 수 없습니다. 확인하지 못한 것: ① 03:12 접속에서 무엇을 열람 · 내려받았는지 ② 다른 계정도 도용됐는지 ③ 이미 받아 간 자료가 있는지.

- (라) 🔍 확인하지 못한 것을 확인하려면 어느 기록에서 무엇을 봐야 하나요?
  - 쓸 내용: ① 볼 기록 이름 ② 그 기록에서 찾을 것 두 가지(시각 · 접속 IP · 계정 중에서)
  - 답: SaaS 의 활동 기록(열람 · 다운로드)에서 03:12 이후 lee 계정의 활동과, 같은 IP 192.0.2.88 에서 다른 계정의 접속이 있었는지를 봅니다.

- (한 줄) 고객에게 보낼 답을 한 문장으로 적어 주세요.
  - 쓸 내용: 고객이 바로 읽을 수 있는 한 문장(확인된 것과 확인 중인 것을 함께)
  - 답: *새벽3시 로그인은 회사 방화벽을 지나지 않은 SaaS 직접 접속입니다. 비밀번호는 바꿨고, 열람 · 다운로드 여부는 서비스의 활동 기록으로 확인 중입니다.」*

### 문제 3-1 · 구성도 두 개를 읽고 DMZ 판정하기

- (가) 구성도 가 와 나 에서 웹 서버가 있는 구역을 각각 적어 주세요.
  - 쓸 내용: 「가: … / 나: …」
  - 답:  구성도 가: INSIDE(내부망), 구성도 나: DMZ 입니다.

- (나) 🔍 두 구성도 중 DMZ 가 있는 것은 어느 것이고, 그렇게 본 근거는 무엇인가요?
  - 쓸 내용: ① DMZ 가 있는 구성도 이름 ② 웹 서버가 있는 구역을 써서 근거
  - 답: 구성도 나 에 DMZ 가 있습니다. 웹 서버가 내부 서버(DB)와 다른 구역(DMZ)에 있기 때문입니다. 구성도 가 는 웹 서버가 내부망 안에 DB 와 같이 있어 DMZ 가 없습니다.

- (다) 웹 서버가 해킹당했을 때, 가 와 나 에서 각각 내부 서버로 가려면 방화벽을 몇 번 지나야 하나요?
  - 쓸 내용: 「가: … 번 / 나: … 번」
  - 답: 구성도 가: 0 번(같은 구역이라 방화벽을 지나지 않고 바로 닿음). 구성도 나: 1 번(FW).

- (라) 🔍 구성도 나 에서 `FW` 와 DMZ 를 잇는 선이 끊기면 영향받는 접속과 영향 없는 접속은 각각 무엇인가요?
  - 쓸 내용: 「영향받는 것: … / 영향 없는 것: …」
  - 답: 영향받는 것: 인터넷에서 웹 서버(WEB)로 가는 공개 웹 접속과 WEB 에서 DB 로 가는 접속(WEB 이 DMZ 선을 지나 DB 로 가기 때문입니다). 영향 없는 것: 내부망 안의 PC · DB 끼리의 접속(FW 와 INSIDE 를 잇는 선은 따로 있음).
